# Contributing to LMS

Thank you for your interest in contributing to the Learning Management System (LMS) project! We welcome all kinds of contributions to improve the project, from fixing bugs and improving documentation to building new features.

## ✨ How to Contribute

1. **Fork the repository**
   - Click the "Fork" button on the [main repository page](https://github.com/Indraja-54/lms)

2. **Create a new branch for your changes:**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes and test them locally.**

4. **Commit your changes:**
   ```bash
   git commit -m "Add: your meaningful commit message"
   ```

5. **Push to your fork:**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Create a Pull Request**
   - Go to your forked repository on [GitHub](https://github.com)
   - Click "New Pull Request" to create a PR from your branch to the main branch of the original repository

## 📖 Guidelines

- **Code Style**: Follow the existing code style (use [Prettier](https://prettier.io/)/[ESLint](https://eslint.org/) where applicable)
- **Pull Request Size**: Keep pull requests focused and small
- **Commit Messages**: Write meaningful commit messages following [conventional commits](https://conventionalcommits.org/)
- **Bug Fixes**: If you're fixing a bug, mention the related [Issue ID](https://github.com/Indraja-54/lms/issues) in your PR description
- **Documentation**: Add comments to complex logic if necessary
- **Testing**: Test your changes thoroughly before submitting

## 🐛 Reporting Issues

Found a bug or have a feature request? Please check our [existing issues](https://github.com/Indraja-54/lms/issues) first, then:

1. Go to the [Issues page](https://github.com/Indraja-54/lms/issues)
2. Click "New Issue"
3. Choose the appropriate template
4. Fill in the details with as much information as possible

## 💡 Feature Requests

Have an idea for a new feature? We'd love to hear it!

1. Check [existing feature requests](https://github.com/Indraja-54/lms/issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement)
2. If it doesn't exist, [create a new issue](https://github.com/Indraja-54/lms/issues/new)
3. Use the feature request template
4. Describe your idea in detail

## ✏️ Need Help?

If you're unsure about anything, feel free to:

- [Open an issue](https://github.com/Indraja-54/lms/issues/new) and ask for guidance before starting

We're happy to help!

## 🏷️ Labels

We use labels to categorize issues and pull requests:

- `bug` - Something isn't working
- `enhancement` - New feature or request
- `documentation` - Improvements or additions to documentation
- `good first issue` - Good for newcomers
- `help wanted` - Extra attention is needed
